# Ontario Universities Program Finder

A Streamlit web application designed to help students evaluate and search undergraduate programs across Ontario universities based on course prerequisites, admission averages, and academic streams.

## Features
- Search and filter 434+ undergraduate programs across Ontario.
- Input Grade 12 (4U/4M) course marks to evaluate eligibility.
- Built with Python, Streamlit, and Pandas.
